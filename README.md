# RCEL-506-Final
RCEL 506: Final Examination Repository
Welcome to the official landing page of Kai Niland's RCEL 506 Final Examination. Within the repository, several files are accessible for review. 

Files noted as week_xx_session_yy_kn63 are JSON files summarizing weekly correspondence with OWLET
Two additional files serve as key JUPYTER files showcasing OWLET's transition from data cleaning to visualization. 

Week_3_4_5_6_(Midterm).ipynb displays data visualization completed through the Exploratory Data Analysis period; a Pearson correlation analysis (R Value) was performed to determine the linear relationship between discipline labor hour density vs project rework. 

Identifying that the Pearson analysis was sensitive to outliers prompted further exploration of data analysis: RCEL506Final.ipynb displays a plethora of code (completed via a gradual audit alongside OWLET) to display Huber slope coefficient values pertaining to specific work scopes.

A multiple-regression analysis was completed alongside the introduction of Huber loss function: MSE on small errors and MAE on larger errors to streamline severe outliers. 

The business proposition of the predictive analytic model is to showcase, via a model much less prone to outlier distortion, which construction disciplines are most likely to experience rework. 

This allows project managers to adequately hire and employ quality surveillance staff who are able to catch installation errors mid-construction.
